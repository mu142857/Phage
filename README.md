# Phage (working title)

A 2D action game about a 4×8 pixel nanobot fighting pathogens inside a host body. 

一款关于 4×8 像素纳米机器人在宿主体内对抗病菌的极简 2D 横版动作游戏。

## Status

In development. Target: playable demo before Sept 2026 (start of Fall term).

## Tech

- **Engine**: Godot 4.6.2.stable
- **Language**: GDScript
- **Art**: Aseprite (source files in `Aseprite Assets`, exported PNGs co-located with entities)
- **Audio**: TBD
