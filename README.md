# Phage (working title)

A 2D action game about a 4×8 pixel nanobot fighting pathogens inside a host body. Inspired by Hollow Knight and Cuphead in combat feel, but minimalist in art direction.

一款关于 4×8 像素纳米机器人在宿主体内对抗病菌的 2D 横版动作游戏。战斗手感参考空洞骑士与茶杯头，美术走极简路线。

## Status

In development. Target: playable demo before Sept 2026 (start of Fall term).

## Tech

- **Engine**: Godot 4.x
- **Language**: GDScript
- **Art**: Aseprite (source files in `Aseprite Assets/`, exported PNGs co-located with entities)
- **Audio**: TBD
